# Model Library research: Indic and Asian / Middle-East / African ASR (sherpa-onnx)

Date of research: 2026-11-10. Latest sherpa-onnx at that date: v2.0.1 (2026-10-26). Sources: Hugging Face API/model cards, k2-fsa/sherpa-onnx `asr-models` release assets (sizes and GitHub SHA-256 digests), moonshine-ai LICENSE, Qwen/Omnilingual/Dolphin cards.

Rules: numbers not found in a primary source are written `not published` or `unverified`. Download bytes = size of the tar.bz2 (release assets) or sum of required HF files. RAM is a heuristic estimate (see `ram_method` in the JSON), not measured. RTF values in cards are GPU unless stated; no CPU RTF was found for any model except the uploader claim for IndicConformer.

## Best in class per group

- **Hindi/Marathi/Telugu/Kannada/Bengali/Gujarati/Malayalam/Tamil/Urdu/Punjabi etc.**: IndicConformer (AI4Bharat, MIT) in sherpa nemo_ctc form. Compact 138 MB per-language (ta/te/ml) or 659 MB per-language 22-language set. Hindi alternative with streaming and 35 languages: Nemotron 3.5 (FLEURS Hindi 6.81).
- **Bengali streaming**: Vosk bn zipformer (Fleurs 20.6, Kathbath 19.3).
- **Long-tail / African (Swahili etc.)**: Omnilingual CTC 300M (Apache-2.0). No dedicated Swahili sherpa model was found; Whisper Swahili fine-tunes exist (cdli, Apache-2.0) but need conversion and have no verified WER here.
- **Mandarin / dialects**: FireRedASR2 AED (CER 3.05 avg), compact: x-asr zipformer zh-en or SenseVoice. **Cantonese**: SenseVoice, wenetspeech-yue u2pp CTC.
- **Japanese**: Parakeet-TDT-CTC 0.6B ja (JSUT CER 6.4). **Korean**: Nemotron 3.5 (FLEURS 7.12) or Qwen3-ASR. **Thai/Indonesian/Vietnamese/Arabic/Turkish**: Qwen3-ASR 0.6B for breadth; dedicated: zipformer-vi, zipformer-thai, Whisper-small-tr.
- **Persian**: Shenava-Koochik (FLEURS-fa WER 10.64). **Hebrew**: Nemotron 3.5 (no good sherpa-format Hebrew model found).

## Licence blockers found

- Moonshine non-English legacy models (ar, ja, ko, zh, vi, uk): non-commercial (moonshine-ai LICENSE). MMS: CC-BY-NC-4.0. Vietnamese zipformer-vi-30M (hynt): CC-BY-NC-ND-4.0. SenseVoice/Paraformer: FunASR custom licence, read before redistributing. AI4Bharat IndicConformer HF repos are MIT but auto-gated (use a repack, keep MIT notice). Cohere Transcribe is Apache-2.0 but gated upstream.
