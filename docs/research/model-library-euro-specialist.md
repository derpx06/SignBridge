# Model Library: English, European, streaming, specialist ASR + cleanup LLMs

Researched 2026-11-10. Sources: k2-fsa/sherpa-onnx `asr-models` release (asset sizes + checksum.txt SHA-256), Hugging Face model cards and API, project `cleanup-model-bakeoff.md`. Machine-readable twin: `model-library-euro-specialist.json`.

Method notes
- Download bytes = sherpa-onnx tarball size (upper bound; some tarballs bundle extra files such as fp32 alongside int8). GGUF rows are the single file.
- Peak RAM is an ESTIMATE, not measured: 1.5 x tarball bytes for int8 ONNX; 1.2 x file for GGUF unless a measured RSS from the project bake-off is stated.
- WER is as published on the model card (FP32 weights; int8 export WER is not published). "computed" = unweighted mean of card per-dataset values, done by me. Open ASR leaderboard CSV/API was private/unreachable, so no leaderboard-only numbers were used.
- SHA-256 for sherpa rows is from release `checksum.txt` of the tarball; GGUF from HF LFS.
- Table cells with `unverified` / `not published` mean exactly that.

## Gaps (no dedicated sherpa-onnx model found; do not invent)
- Telephony 8 kHz: none packaged. T-one (Russian) is the only call-style candidate; 8 kHz suitability unverified. Resample + generic models otherwise.
- Children, accented English, noisy: no dedicated models. Parakeet v2 card has an SNR noise-robustness table; Qwen3-ASR card reports an internal accented-English set (0.6B figures not isolated).
- Hinglish / Spanglish code-switching: no dedicated model; multilingual Whisper and Qwen3-ASR are the only plausible candidates, unevaluated here. Hinglish belongs to the Indic list.
- Greek, Czech, Polish, Nordic, Turkish, Ukrainian: covered only via Parakeet v3 (bg cs da el et fi hr hu lt lv mt nl pl pt ro sk sl sv uk ru) and Nemotron 3.5 (tr, uk, nl...). No separate specialist found. Italian and Portuguese specialists: pt FastConformer exists in release (sherpa-onnx-nemo-transducer-stt_pt_fastconformer_hybrid_large_pc-int8, 106541116 B) but was not carded.

## Suggested shipping set
Parakeet 110M (low RAM EN), Parakeet v2 (EN best), Parakeet v3 (EU), Canary 180M Flash (en/es/de/fr small), Nemotron streaming EN + 3.5 multilingual streaming, Whisper small (long tail), GigaAM v3 (ru), Silero VAD, S1-mini cleanup LLM.
